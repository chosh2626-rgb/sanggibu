# 모의면접 자료 생성기

학교생활기록부만 올리면, 지원 대학의 **2027학년도 수시 모집요강·면접 안내·기출 문항을 웹에서 자동으로 찾아** 학생 맞춤 모의면접 자료(HTML·PDF)를 만들어 주는 웹 페이지입니다.

## 바로 쓰기

GitHub Pages를 켜면 아래 주소에서 열립니다.

```
https://<계정명>.github.io/<저장소명>/
```

켜는 방법: 저장소 **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**. 1~2분 뒤 위 주소로 열립니다.

## 사용 순서

1. **학생·지원 정보**: 학생명, 대학명, 모집단위(학과), 전형명을 입력합니다.
2. **학교생활기록부 올리기**: PDF(나이스 출력 권장), DOCX, TXT, HTML, 이미지를 올리거나 텍스트를 붙여넣습니다. HWP는 PDF로 저장해서 올려 주세요.
3. **자동 검색**: 별도 자료 없이 대학명·학과·전형으로 웹을 검색합니다. 필요하면 "검색할 때 더 챙길 점"을 적습니다.
4. **Claude API 키**를 입력하고 **면접 자료 생성**을 누릅니다. 보통 4~8분 걸립니다.
5. 결과를 **미리보기**로 확인하고 **HTML 저장 / PDF 저장 / 코드 복사**로 가져갑니다.

### 자동으로 찾는 자료
- 2027학년도 수시모집요강(입학처): 모집인원, 선발 방법, 수능최저, 면접 방식·시간, 평가요소
- 학생부종합전형 안내서, 면접 안내, 선행학습영향평가보고서의 면접 문항
- 대학이 미리 공개한 사전 질문 (있으면 자료에 10번 섹션이 자동으로 추가됨)
- 인재상, 학과 교육목표·교육과정
- 대입정보포털 어디가, 교육청 자료집, 입시 사이트의 기출·후기

검색한 내용은 **검색 자료** 탭에서 확인하고 고칠 수 있습니다. 고친 내용은 다음 생성부터 쓰입니다. 같은 대학·학과·전형은 저장된 검색 결과를 다시 쓸 수 있어, 여러 학생 자료를 만들 때 검색 비용과 시간을 아낄 수 있습니다.

## Claude API 키

- [Claude Console](https://platform.claude.com/settings/keys)에서 발급합니다. 사용료는 **키 주인에게 청구**됩니다.
- 웹 검색 사용료는 검색 1,000회당 10달러에 토큰 사용료가 더해집니다. 자료 1건당 검색은 최대 15회입니다. 최신 요금은 [가격 안내](https://www.anthropic.com/pricing)를 확인하세요.
- 조직 설정에서 웹 검색이 꺼져 있으면 검색 단계가 실패합니다. Console의 설정에서 웹 검색을 켜 주세요.
- 키는 Anthropic API로만 보냅니다. "이 브라우저에 키 기억하기"를 켜면 그 브라우저에만 저장됩니다. 공용 컴퓨터에서는 끄세요.

## 출력 구성

1. 대학 및 전형 분석 표
2. 면접 유형 판별 및 실제 출제경향
3. 인재상 및 학과 커리큘럼 연계
4. 면접관이 주목할 학생부 TOP 10
5. 맞춤 예상 질문과 모범답안, 꼬리질문 (10문항)
6. 전공 학업 심화 질문
7. 인성·공동체 질문
8. 반드시 대비해야 할 위험 질문
9. 모의면접 평가표 (100점 만점)
10. 대학 사전 공개 질문 모범답안 (공개 대학만)
- 확인이 필요한 사항 / 참고 출처 (웹 검색)

## 작성 원칙

- 전형 정보는 웹 검색으로 찾은 자료에만 근거하고, 찾지 못한 내용은 ❓/⚠️로 표시합니다. **모집인원·일정 등은 반드시 입학처 공식 자료로 다시 확인하세요.**
- 학생부에 없는 경험은 만들지 않고, 학생 확인이 필요한 부분은 `[학생 본인의 실제 경험 확인 필요]`로 표시합니다.
- 실제 기출 / 기출 변형 / 예상 문항을 구분합니다.

## 개인정보

- 이 페이지에는 학생 자료가 들어 있지 않습니다. 생기부 내용은 생성할 때 사용자의 브라우저에서 Anthropic API로만 보냅니다.
- 생성 결과와 검색 결과는 그 브라우저에만 저장됩니다.
- **학생 생기부나 생성된 자료를 이 저장소에 올리지 마세요.** 공개 저장소는 누구나 볼 수 있습니다.
