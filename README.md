# 모의면접 자료 생성기

학교생활기록부, 대학 수시 모집요강, 면접 기출·안내 자료를 올리면 학생 맞춤 모의면접 자료를 HTML로 만들어 주는 도구입니다.

## 파일 구성

| 경로 | 내용 |
| --- | --- |
| `mock-interview.html` | 생성기 페이지 (Claude Artifact로 게시해 사용) |
| `examples/예시.html` | 출력 형식 예시 (일반 서류 기반 면접 대학) |
| `examples/예시(사전면접질문공개대학용).html` | 출력 형식 예시 (사전 면접 질문 공개 대학, 10번 섹션 포함) |
| `prompt/모의면접.txt` | 원본 프롬프트 (분석 원칙·출력 형식·검증 사항) |

## 중요: 생성 기능이 작동하는 환경

`mock-interview.html`은 Claude Artifact의 `sample`(Claude 호출)·`downloads`(파일 저장) 기능을 사용합니다.
**claude.ai 또는 Claude 앱 안에서 Artifact로 열 때만 생성 버튼이 작동**합니다.
브라우저에서 파일을 직접 열거나 GitHub Pages에 올리면 화면만 보이고 생성은 비활성화됩니다.

## 사용 방법

1. 학생명, 대학명, 모집단위(학과), 전형명을 입력합니다.
2. 자료를 올립니다.
   - 학교생활기록부 (필수, 나이스 출력 PDF 권장)
   - 대학 수시 모집요강 (필수, 해당 학과·전형·면접 쪽을 골라 사용)
   - 면접 기출·안내 자료 (권장, 선행학습영향평가보고서·면접 안내 등)
   - PDF, DOCX, TXT, HTML, 이미지 지원. HWP는 PDF로 저장 후 업로드.
3. 사전 면접 질문을 공개한 대학이면 옵션을 체크합니다. 문항을 입력하거나 비워 두면 자료에서 찾습니다.
4. **면접 자료 생성**을 누릅니다 (보통 2~5분).
5. 미리보기 확인 후 **HTML 파일 저장** 또는 **코드 복사**.

## 출력 구성

1. 대학 및 전형 분석 표
2. 면접 유형 판별 및 실제 출제경향
3. 인재상 및 학과 커리큘럼 연계
4. 면접관이 주목할 학생부 TOP 10
5. 맞춤 예상 질문과 모범답안, 꼬리질문 (10문항)
6. 전공 학업 심화 질문
7. 인성·공동체 질문
8. 반드시 대비해야 할 위험 질문
9. 모의면접 평가표 (100점 만점)
10. 대학 사전 공개 질문 모범답안 (해당 대학만)
- 확인이 필요한 사항

## 작성 원칙

- 웹 검색을 하지 않습니다. 전형 정보는 올린 모집요강·기출 자료에서만 가져오며, 확인되지 않은 내용은 ❓/⚠️로 표시합니다.
- 학생부에 없는 경험은 만들지 않으며, 학생 확인이 필요한 부분은 `[학생 본인의 실제 경험 확인 필요]`로 표시합니다.
- 실제 기출 / 기출 변형 / 예상 문항을 구분합니다.
