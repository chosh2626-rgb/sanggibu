Q1. 3학년 진로활동에서 2차전지 제조 시스템을 대상으로 선형계획 모델을 수립하고 병목공정을 찾아냈습니다. 모델의 목적함수와 제약조건을 어떻게 설정했으며, 병목공정은 어떤 기준으로 도출했습니까?

• 평가 요소: 진로탐구역량(경영과학/선형계획법 모델링), 논리적 문제해결력 | 난이도: Level 4
"2차전지 셀 생산의 이익을 극대화하기 위해 각 제품의 단위당 순이익을 계수로 하고 생산량을 결정변수로 두어 총이익을 최대화하는 선형 목적함수를 수립했습니다. 제약조건으로는 전극 공정, 조립 공정, 활성화 공정 등 각 단위 공정의 '일일 최대 가용 설비 시간'과 시장에서의 '최대 수요량'을 설정했습니다. 엑셀 해찾기(Solver)를 통해 심플렉스 알고리즘으로 최적 생산량을 도출한 뒤 자원 여유분(Slack)을 분석했습니다. 그 결과 가용 설비 시간을 100% 모두 소진하여 여유 시간이 0이 되는 공정이 전체 라인의 흐름을 지연시키는 '병목(Bottleneck) 공정'임을 수학적으로 확인했습니다. 이를 통해 생산량 확대는 무작정 인력을 투입하는 것이 아니라 이 병목 공정의 처리 용량을 개선할 때만 가능하다는 산업공학의 핵심 원리를 배웠습니다."
• 핵심 키워드: 목적함수, 의사결정변수, 가용시간 제약, 여유분(Slack), 병목공정, 최적 자원배분
• 꼬리질문 1: 실제 제조 현장은 장비 고장이나 작업자 숙련도 같은 확률적 변수가 많은데, 정적 선형계획 모델의 한계는 어떻게 보완할 수 있습니까?
• 꼬리질문 2: 병목 공정을 해결하기 위해 탐구에서 언급한 '강화학습'을 도입한다면 에이전트의 보상함수(Reward)는 어떻게 설계하겠습니까?
• 꼬리질문 3: 선형계획법(LP)에서 제약조건의 우변 상수가 1단위 증가할 때 목적함수 값이 변화하는 양을 뜻하는 '잠재가격(Shadow Price)' 개념을 알고 있습니까?
Q2. 3학년 진로활동에서 RAG와 센서 데이터를 결합한 공정 품질예측 자동화 시스템을 구축하며 n8n 툴을 활용했습니다. 파이프라인 구축 중 발생한 오류의 원인과 이를 해결한 과정을 설명해 보세요.

"제조 공정의 온도, 압력, 모터 RPM 센서 데이터와 과거 불량 이력 보고서를 결합하여 실시간으로 불량을 예측하는 n8n 자동화 워크플로우를 설계했습니다. 시스템 구현 중 '새로운 공정 데이터가 벡터 DB에 임베딩되어 저장되기도 전에 RAG 검색 노드가 먼저 실행'되거나, 센서 노드 간 통신 지연으로 필수 입력값이 누락되어 LLM이 엉뚱한 예측을 내놓는 비동기 처리 오류가 발생했습니다. 저는 데이터 흐름 추적 로그를 분석해 병렬 처리 노드를 순차적 실행 트리거로 재설계했습니다. 데이터 검증 노드를 신설하여 결측치가 발생하면 이전 단계로 재요청을 보내거나 기본 보간값을 대체하도록 파이프라인을 수정함으로써 시스템의 데이터 정합성과 안정성을 확보할 수 있었습니다."

Q3. 3학년 동아리활동에서 MediaPipe 딥러닝 기술과 제조업의 SPC(통계적 공정관리) 기법을 융합하여 '실시간 거북목 예방 시스템'을 개발했습니다. 제조업의 품질 관리 기법을 인체 자세 교정에 어떻게 접목했습니까?
• 질문 근거: 3학년 동아리활동(엔크크) 세특 (MediaPipe 신체 랜드마크 가시성 점수, 이동 평균 필터 노이즈 제거, 제조업 SPC 기법 개인별 자동 UCL 도출)
• 평가 요소: 진로탐구역량(통계적 품질관리 및 인간공학 융합), 창의적 문제해결력 | 난이도: Level 4

Q1. 3학년 데이터과학과 머신러닝 세특에서 거시 경제 지표와 핀테크 이용량의 상관관계를 분석하고 '머신러닝 학습 데이터 편향의 윤리적 문제'를 지적했습니다. 데이터 편향이 산업 시스템 최적화에 미치는 영향과 이를 기술적으로 보정하는 방안은 무엇입니까?
